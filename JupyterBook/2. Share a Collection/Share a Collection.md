# Share a Collection

Once you have created a Collection, you can share it with other Glycerine Workbench users so you can work on the same images together. Each person you share it with has one of two roles:

- **Collaborator**: can add their own Image Sets to the Collection and annotate any Image Set in it.
- **Annotator**: can annotate any Image Set in the Collection, but can’t add or change Image Sets.

Everything in the Collection belongs to whoever created it. Only the person who created an Image Set can change, publish or delete it, and only the person who created an Annotation Set can edit or publish it, so nobody can change your annotations, not even the Collection owner. The one exception: whoever owns an Image Set can delete any Annotation Set on it. Only the Collection owner can share the Collection with others.

1.	Press **Share**.
2.	Enter the email address of the person’s Glycerine Workbench account, and choose their role: **Collaborator** or **Annotator**. They must already have a Glycerine Workbench account.
3.	Press **Share**.

The Collection appears in their Glycerine Workbench straight away. There’s nothing for them to accept, so you may want to let them know you’ve shared it.

Under **Users**, you can also press the **x** button to remove users you’ve already shared with.
